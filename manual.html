泉威食品 - LINE 訂購系統

操作圖文說明書

適用對象：門市、加盟主、內勤下單人員

版本日期：2026-01-17

1. 系統目的與使用範圍

本系統用於簡化訂貨流程，讓店家可直接透過 LINE 提交訂購需求。

適用情境包含：日常補貨、追加訂購、出貨日前例行下單。

2. 操作流程總覽

  • 進入訂購單頁面並填寫基本資料。
  • 新增訂購品項：選擇產品並輸入數量（可多筆）。
  • 進入核對頁確認資料，必要時返回修改。
  • 確認送出，送出成功後關閉視窗返回 LINE。

3. 詳細操作步驟

步驟 1：進入系統與填寫基本資料

  • 下單日期：系統自動帶入當天日期（無需手動輸入）。
  • 店家名稱（必填）：輸入店名或客戶名稱，以利後台辨識與出貨。
  • 訂購人（LINE）：系統自動帶入您的 LINE 名稱。
  • 預計出貨日期（必填）：點擊欄位選擇希望的出貨日期。
  • 訂購項目（必填）：至少新增 1 筆品項並輸入數量。
  • 完成後點「下一步：核對內容」進入核對頁。

圖 1. 基本資料與訂購項目

步驟 2：選擇訂購品項（下拉清單）

  • 點選品項文字列即可選擇該品項。
  • 右側圓點代表選取狀態，點選後即完成選擇。
  • 可上下滑動清單尋找所需品項。

圖 2. 品項下拉選單

步驟 3：新增多筆品項與輸入數量

  • 於下拉選單選擇產品，並在數量欄位輸入需求數量。
  • 如需多樣產品，點「+ 增加一筆品項」新增下一筆。
  • 若某筆不需要，可點紅色 X 刪除該筆。
  • 全部填寫完成後，點「下一步：核對內容」。

圖 3. 多筆品項與數量輸入

步驟 4：核對訂單內容

  • 核對基本資訊：店家、出貨日、訂購人是否正確。
  • 逐筆確認品項名稱與數量。
  • 若需調整，點「返回修改」回上一頁修正。
  • 確認無誤後點「確認送出」。

圖 4. 核對頁（送出前最後確認）

步驟 5：送出成功與完成

  • 看到「訂單已送出成功！」即完成送單。
  • 系統會顯示訂單摘要（店家、出貨日與品項清單）供留存。
  • 點「關閉視窗」返回 LINE 對話。

圖 5. 送出成功畫面

4. 注意事項

  • 星號（*）欄位為必填：未填寫將無法進入下一步。
  • 送出後若需更改內容：請依公司內部流程處理（例如聯繫客服或於 LINE 視窗補充/更正）。
  • 若畫面載入過久：請確認網路狀態，必要時關閉視窗後重新進入。
